# SoulBiz

A Next.js prototype for AI-assisted relationship reflection, tarot-style daily prompts and a lightweight growth funnel.

The repository name is retained to keep existing links and deployments stable.

## Implemented areas

- Relationship-analysis and daily-prompt product pages.
- Shared growth event collection and automatic page-view tracking.
- Funnel events for analysis starts, completions and sharing.
- A growth dashboard with visits, completion rates, traffic sources and popular pages.
- Cloudflare/OpenNext and Vercel deployment configuration.

## Run locally

```bash
npm install
npm run dev
```

Production builds:

```bash
npm run build
```
