# 角色文档：运维 / SRE

## 目标
- 保证中国用户访问稳定，出现故障可快速定位和回滚。

## 发布策略
- 主环境：Cloudflare（含 CDN/SSL）。
- 备环境：Railway / Vercel（用于快速切换）。
- 部署方式：`main` 自动部署 + tag 版本回滚。

## 必做项
1. `P0` 健康检查：`/api/health` 接口 + 外部探针。
2. `P0` 监控：请求量、5xx、超时、地区分布。
3. `P0` 告警：5xx 激增、OCR 成功率下跌、延迟飙升。
4. `P1` 发布保护：灰度发布 + 一键回滚。
5. `P1` 日志分桶：OCR、分析、支付、留资分开。

## SLA 建议
- 可用性：99.5%。
- 故障恢复：30 分钟内恢复服务。
- 回滚耗时：10 分钟内完成。

## 验收
- 连续 7 天无 P0 故障。
- 发生故障时可在 5 分钟内确定故障域。
