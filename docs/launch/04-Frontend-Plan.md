# 角色文档：前端工程师

## 目标
- 提升移动端可用性与感知速度。
- 降低“上传后无结果”的用户感受。

## 任务清单（按优先级）
1. `P0` 进度 UI：分阶段明确显示（上传、OCR、分析、生成）。
2. `P0` OCR 失败后在页面内显示“失败原因 + 一键重试”。
3. `P0` 结果页空数据兜底文案（避免“0 消息”体验崩塌）。
4. `P1` 图片预处理：自动压缩并提示建议截图数量。
5. `P1` 首屏性能优化：图像懒加载、减少阻塞脚本。
6. `P2` 分享卡模板统一（更像产品，而不是 demo）。

## 技术要求
- 所有请求走统一 `fetchWithTimeout` + 错误码映射。
- 页面加载骨架屏与按钮 loading 状态保持一致。
- 移动端 Safari 与微信内置浏览器双测。

## 验收标准
- 上传到报告成功率 > 85%（真实线上）。
- 失败后重试成功率 > 50%。
- 首屏 LCP（4G）< 3.0s。
