# 多 Agent 协作执行手册

## 参与角色
- 需求分析师
- 架构设计师
- UI/UX 设计师
- 前端工程师
- 后端工程师
- 测试工程师
- 运维/SRE
- 数据增长
- 安全法务
- 验收负责人
- Marketing

## 并行协作机制
1. `产品 + 架构 + UIUX` 同步定义目标与范围。
2. `前端 + 后端 + QA` 并行开发与回归。
3. `SRE + 安全法务` 并行做上线前门禁。
4. `增长 + Marketing` 在小流量期同步跑实验。

## 每日节奏
- 10:00 站会：阻塞项、当天目标、风险预警。
- 16:00 同步：功能状态、指标波动、决策确认。
- 22:00 复盘：当天产出、明日优先级、是否发布。

## 决策规则
- 涉及稳定性与合规：SRE/法务一票否决。
- 涉及用户体验：UIUX 与产品联合拍板。
- 涉及投入产出：增长数据优先。

## 当前 14 天冲刺计划
1. D1-D3：完成 P0 稳定性改造（OCR、超时、错误码、监控）。
2. D4-D7：完成移动端体验优化与报告页改版。
3. D8-D10：完成支付/留资闭环与数据看板。
4. D11-D14：小流量投放、A/B 测试、发布评审。

## 里程碑定义
- M1：主流程成功率 > 85%。
- M2：次日留存 > 20%，分享率 > 8%。
- M3：付费或留资转化达到目标并可复现。
