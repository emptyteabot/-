# 角色文档：安全 / 隐私 / 法务

## 高风险点
- 用户上传聊天截图属于敏感个人信息。
- 涉及第三方模型处理，需透明告知。
- 若无授权声明，存在合规风险。

## 必做合规动作
1. 上传前明确提示并二次确认授权。
2. 最小化数据：默认不长期保存原图。
3. 提供“删除请求”入口与处理时限。
4. 隐私政策写明第三方处理商类别和用途。
5. 禁止生成确定性医疗/法律结论。

## 安全基线
- 环境变量与密钥仅在服务端。
- API 限流、防刷、防重放。
- 日志脱敏（联系方式、ID、聊天内容片段）。

## 发布门槛
- 隐私政策与用户协议页面可访问且内容完整。
- 完成一次内部合规审查并记录。
