# 角色文档：需求分析师（PRD）

## 目标用户
- 情绪焦虑、关系不确定的中文用户。
- 使用场景：怀疑关系变化、需要“可执行建议”而非长篇心理学解释。

## 核心价值主张
- 60 秒内上传。
- 120 秒内拿到可读报告。
- 报告必须包含：结论、证据、风险、下一步行动。

## 核心用户流程
1. 进入落地页 -> 选择“情感法医”。
2. 上传 3-8 张连续聊天截图。
3. 等待 OCR + 分析（有实时进度）。
4. 查看报告 -> 分享/再次分析/提交线索。

## 必做功能（MVP+）
- 批量截图上传与预览。
- OCR 失败重试与分批识别。
- 报告结构化展示（数据 + 文案）。
- 错误提示可理解（用户知道下一步怎么做）。

## 指标定义
- `upload_start_rate`：进入上传页后发起上传比例。
- `ocr_success_rate`：OCR 成功返回有效文本比例。
- `analysis_complete_rate`：完成报告比例。
- `lead_submit_rate`：看完报告后留资比例。
- `share_rate`：生成分享图后分享比例。

## 非功能需求
- 手机端首屏 < 2.5s（中国网络环境）。
- OCR/分析总超时控制 < 90s。
- 可观测：每条失败必须带错误码与 trace id。
