# 角色文档：数据分析 / 增长

## 北极星指标
- `报告完成人数 / 日`（真正拿到价值的人数）。

## 漏斗指标
1. 访问首页
2. 进入关系透视页
3. 上传截图
4. OCR 成功
5. 报告生成成功
6. 留资 / 分享 / 二次分析

## 实验框架
- 实验周期：7 天。
- 只改一个变量：标题、CTA、价格锚点、报告结构四选一。
- 最小样本：每组 300 UV。

## 首批实验
1. 上传区文案 A/B（强调“3-8 张连续截图”）。
2. 报告页 CTA A/B（留资 vs 分享优先）。
3. 免费版长度 A/B（短报告 vs 中报告）。

## 数据治理
- 事件命名统一小写下划线。
- 每个事件必须带：页面、会话、来源渠道。
- 每周输出增长复盘：结论、失败、下周动作。
