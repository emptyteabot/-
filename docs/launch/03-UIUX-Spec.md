# 角色文档：UI/UX 设计师

## 视觉方向
- 风格关键词：`Google/OpenAI 式极简`、`高留白`、`信息层级清晰`。
- 页面原则：每屏只解决一个问题，不堆叠信息密度。
- 字体：中文优先系统可读字族，标题与正文对比明显。

## 核心页面规范
- 首页：1 个主 CTA + 1 个辅助 CTA，不超过 2 块产品卡片。
- 上传页：上传区、预览区、提交按钮三段式，不出现多余营销文案。
- 进度页：显示当前阶段、预计剩余时间、失败后可重试按钮。
- 报告页：先结论再证据，图表不超过 3 个。

## 交互标准
- 所有长耗时动作必须有进度反馈。
- 错误提示必须可行动（例如“请上传原图，至少 3 张连续截图”）。
- 手机端触控热区 >= 44px。

## 可用性验收
1. 新用户首次完成分析 <= 3 分钟。
2. 报告页首屏 5 秒内可看到结论。
3. 关键按钮点击成功率 > 98%（埋点验证）。
