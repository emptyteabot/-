# 角色文档：验收负责人

## 验收清单（Go / No-Go）

## 功能验收
- [ ] 聊天截图上传可用（单图/多图）。
- [ ] OCR 成功率达到目标（> 85%）。
- [ ] 报告结构完整（结论/证据/风险/建议）。
- [ ] 错误提示可读且可执行。

## 质量验收
- [ ] `npm run build` 通过。
- [ ] `npm run lint` 无阻断错误。
- [ ] 关键路径手工测试通过（iOS/Android/PC）。
- [ ] 线上监控可见核心指标。

## 运维验收
- [ ] 主域名可访问（中国网络实测）。
- [ ] 健康检查正常。
- [ ] 回滚脚本可执行。

## 商业验收
- [ ] 付费或留资路径打通至少一种。
- [ ] 数据看板可读取转化漏斗。
- [ ] 客诉处理 SOP 可执行。

## 发布结论
- 若任一 P0 未通过：`No-Go`。
- 全部 P0 通过且 P1 可控：`Go`。
