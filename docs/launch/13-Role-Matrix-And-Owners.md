# 角色责任矩阵（Owner 制）

## 目的
- 防止“都在做事但没人负责结果”。
- 每个角色都有明确产出、节奏、验收标准。

## 角色与 Owner
1. 需求分析师（Owner: Product）
- 产出：PRD、优先级、版本边界。
- KPI：需求返工率 < 15%。

2. 架构设计师（Owner: Architect）
- 产出：系统边界、服务拆分、错误码规范。
- KPI：P0 架构风险清零。

3. UI/UX 设计师（Owner: Design）
- 产出：页面信息层级、移动端交互规范、空状态策略。
- KPI：关键路径完成率提升 > 10%。

4. 前端工程师（Owner: Frontend）
- 产出：上传、进度、报告、营销页体验。
- KPI：前端异常率 < 1%，LCP < 3s（4G）。

5. 后端工程师-AI 网关（Owner: Backend-1）
- 产出：模型路由、超时/重试、限流。
- KPI：5xx < 1%，超时率 < 8%。

6. 后端工程师-业务接口（Owner: Backend-2）
- 产出：OCR/分析/留资/营销 API。
- KPI：主流程成功率 > 85%。

7. 测试工程师（Owner: QA）
- 产出：冒烟清单、回归报告、发布门禁单。
- KPI：阻断缺陷线上泄漏 = 0。

8. 运维/SRE（Owner: SRE）
- 产出：监控告警、发布回滚、故障处理 SOP。
- KPI：可用性 > 99.5%，故障恢复 < 30 分钟。

9. 数据分析（Owner: Data）
- 产出：漏斗看板、实验分析、渠道归因。
- KPI：实验周期内给出可执行结论。

10. 增长/Marketing（Owner: Growth）
- 产出：渠道内容、话术、投放节奏、复盘报告。
- KPI：7 日上传目标达成、留资率稳定增长。

11. 销售/私域（Owner: Sales）
- 产出：私信 SOP、跟进规则、成交脚本。
- KPI：线索转化率逐周提升。

12. 客服/成功（Owner: CS）
- 产出：用户问题分类、话术库、客诉闭环。
- KPI：24h 解决率 > 90%。

13. 法务与隐私（Owner: Legal）
- 产出：协议、隐私、授权提示、删除流程。
- KPI：合规阻断项 = 0。

14. 财务与融资（Owner: Finance）
- 产出：收入结构、成本结构、融资材料数据页。
- KPI：单位经济模型可解释、可复算。
