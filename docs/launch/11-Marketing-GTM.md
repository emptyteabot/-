# 角色文档：Marketing / GTM

## 阶段目标
- 阶段 1：验证价值（完成报告人数增长）。
- 阶段 2：验证付费（付费转化与客诉率可控）。
- 阶段 3：验证规模（渠道可复制、成本可预测）。

## 中国市场优先策略
1. 渠道：小红书 + 抖音 + 私域微信。
2. 内容：案例型短内容（问题 -> 截图 -> 结论 -> 行动建议）。
3. 转化：引导到“免费试用报告”，报告尾部引导进阶服务。

## 产品化营销素材
- 标题模板：`别猜了，先看聊天证据`。
- 卖点模板：`2 分钟看清关系信号`。
- 信任模板：`隐私可控，可打码上传`。

## 商业化路径
- 免费层：短报告 + 分享激励。
- 低价层：完整报告 + 行动清单。
- 高价层：1v1 复盘咨询（人工增值服务）。

## 融资叙事框架
- 问题：情绪决策场景高频、强需求、付费意愿存在。
- 方案：AI 结构化分析 + 快速反馈 + 可执行建议。
- 壁垒：数据闭环、模型路由、转化漏斗与渠道效率。
- 指标：激活、留存、ARPU、复购、获客成本回收周期。
