# Marketing Vibe 实战手册

## 核心打法
1. 内容引流
- 每天 3 条：案例、方法、观点。
- 每条都围绕一个主卖点：`看证据，不猜测`。

2. 私信承接
- 用户评论后 5 分钟内响应。
- 用“先试读报告”降低门槛。

3. 报告转化
- 报告页引导二次动作：留资、分享、再分析。
- 统一收口话术：`结论-证据-下一步动作`。

## 渠道执行模板
1. 小红书
- 标题：冲突 + 结果。
- 正文：短段落，高密度信息。
- 尾部：3-5 个话题标签。

2. 抖音
- 3 秒钩子。
- 20-30 秒给出证据。
- 结尾评论区引导。

3. 微信私域
- 一对一试读。
- 分类跟进：观望 / 立刻购买 / 需要解释。

## 每日 KPI
1. 上传截图人数
2. 报告完成率
3. 留资人数
4. 留资转化率
5. 次日回访率

## 每周复盘
1. 哪类内容带来上传最多
2. 哪类话术留资率最高
3. 哪个环节损失最大（上传、OCR、分析、留资）
4. 下周只保留前 20% 高 ROI 动作
