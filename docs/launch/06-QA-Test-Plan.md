# 角色文档：测试工程师（QA）

## 测试范围
- 上传链路：单图、多图、超大图、模糊图、非聊天图。
- OCR 结果：有文本、空文本、错序文本、拒答文本。
- 分析链路：正常、超时、模型故障、fallback。
- 端兼容：iOS Safari、微信内置浏览器、安卓 Chrome。

## 用例分层
1. `冒烟测试`：主流程 10 分钟内可跑完。
2. `回归测试`：OCR + 分析 + 报告渲染核心路径。
3. `异常测试`：超时、429、500、模型不可用。
4. `性能测试`：并发上传和长文本分析。

## 质量门禁（发布前）
- 阻断级 bug = 0。
- 高优先级 bug <= 2（且有明确绕过方案）。
- 主流程成功率 >= 85%。
- 全平台关键路径通过率 >= 95%。

## 交付物
- 每日测试报告（失败样本 + 复现步骤 + 影响范围）。
- 发布验收单（Go / No-Go）。
